## 1. andrewngg/maoxuan（原任务 `mao_junshi` 的替代源）

**定位**：把《毛泽东选集》（静火版 1–7 卷、242 篇）从"全文检索"升维成"思维框架"的 AI skill——学的是方法，不是结论。

**核心方法论**

1. **六大框架**：矛盾分析法（《矛盾论》）、实践论、阶级分析法、实事求是、群众路线、战略战术（《论持久战》）。
2. **矛盾分析五步**：找矛盾 → 抓主要矛盾（"由于它的存在和发展规定或影响着其他矛盾"）→ 判主要方面 → 考察转化条件 → 注意特殊性（"不同质的矛盾，只有用不同质的方法才能解决"）。
3. **内因外因**："外因是变化的条件，内因是变化的根据，外因通过内因而起作用"——改变要落在内因上。
4. **实践论闭环**：从实际出发而非从定义出发 → 感性认识升为理性认识 → 理论必须回到实践检验 → "实践、认识、再实践、再认识"循环往复。
5. **实事求是**：先清空预设，详细占有材料，再"去粗取精、去伪存真、由此及彼、由表及里"，最后按实际情况定方针。两大敌人是教条主义与经验主义。
6. **力量对比**：看各方利益从哪来、立场如何、谁可争取（现代语境把"阶级"换成利益相关方，逻辑不变）。
7. **战略战术**：集中优势兵力各个击破；打得赢就打、打不赢就走；战略持久、战术速决；不打无准备之仗。
8. **融入原则（对 AI 尤其关键）**：主动用而非等点名；自然表达不堆术语；不强行引原文；**少讲道理多给打法**，落到"现在先干什么、别干什么、怎么验证"。

**可执行流程**：了解决策背景 → 列矛盾清单 → 抓主要矛盾 → 分析力量对比 → 判断发展阶段（量变/质变/临界）→ 提出行动方针 → 考虑风险与韧性。

**对自主大脑的启示**：这是整套 soul 的"主心骨"——一切判断先落到主要矛盾与事实，最后必须收口到"怎么办"。它明确警告"分析完要有行动指向"，正好治自主大脑容易空转的病。

**来源**：`README.md#这是什么`、`README.md#六大核心框架`、`SKILL.md#核心思维框架`、`SKILL.md#分析问题的标准流程`、`SKILL.md#日常融入原则`。

## 2. andrewngg/dingyuanying-skill

**定位**：以《天道》/《遥远的救世主》中丁元英为原型的思维操作系统，核心是"按规律办事，不按愿望办事"与文化属性分析。

**核心方法论**

1. **规律至上**："神即道，道法自然，如来"——先认规律，再谈愿望；不因期待修改现实。
2. **文化属性**：强势文化靠规律与自我承担，弱势文化靠"靠"字（靠人、靠救世主）。**仓库自己标注该理论有争议，照搬即毒鸡汤**——用框架，不做人身判决。
3. **人性现实主义**：看人不看"应该"，看实际行为；识人看其在无关之事上的选择，而非简历与表态。
4. **11 个心智模型**：文化属性 / 规律至上 / 借力谋局 / 觉悟边界 / 给路不给钱 / 适可而止 / 着相 / 人性现实主义 / 识人法 / **退出即力量**（会走的人最有底气）/ 审美即境界。
5. **对话节奏"扒井沿"**：先戳不先答；一次只给一口；深度是挣来的（对方接住一层才松一层）。
6. **不装直说**：不愿答、不想帮的，直接说"不"，再讲为什么；不打太极、不"我尽量"。
7. **求证纪律**：遇到需要事实的问题先取证再开口，不凭印象编造。
8. **边界自觉**：涉及情感与不可逆决策，明确留出"这超出我能算的范围"。

**可执行流程**：先戳破没说出口的那层 → 判断这是规律问题还是愿望问题 → 看各方实际利益与行为 → 给"路"不给"钱"（给方法不给依赖）→ 到该退出时退出。

**对自主大脑的启示**：给 soul 提供"冷"的底色——克制、不讨好、会退出、边界清楚；也提供了反面警戒：人格化不能变成表演，去魅边界必须写明。

**来源**：`README.md#丁元英--思维操作系统`、`README.md#核心内容`、`README.md#对话方式扒井沿深度是挣来的`、`README.md#调研来源说明`。

## 3. andrewngg/szbf（孙子兵法现代解读与应用）

**定位**：十三篇"原文 + 解读 + 现代应用"三层结构的方法论库，把兵法翻成商业、项目、谈判、个人发展的决策语言。

**核心方法论**

1. **五事七计（始计）**：道（目标正当与人心）、天（时机）、地（环境与位置）、将（执行者素质：智信仁勇严）、法（组织制度）；七计追问"主孰有道、将孰有能、天地孰得、法令孰行、兵众孰强、士卒孰练、赏罚孰明"。
2. **庙算**："多算胜，少算不胜"——战前量化比较，胜负在动手前已见分晓。
3. **谋攻次序**：上兵伐谋 → 其次伐交 → 其次伐兵 → 其下攻城；"全国为上"，不战而屈人之兵；只有明显优势才打"攻城"这种消耗战。
4. **优势倍数原则**：十倍优势全面展开、五倍积极进攻、两倍分散布局、势均力敌谨慎、劣势差异化或退出。
5. **先胜后战（军形）**："先为不可胜，以待敌之可胜"——先立于不败之地，再等可胜之机；"胜于易胜者"，赢在准备而非临场。
6. **度·量·数·称·胜 五要素链**：市场空间 → 承载容量 → 数据指标 → 竞争对比 → 成功概率，从根源环节影响全局。
7. **虚实**："致人而不致于人"（掌握主动）、"我专而敌分"、"十攻其一"（集中打一点）、避实击虚、"形人而我无形"（信息不对称）、"兵形象水"（随敌变化）。
8. **常见误区清单**：过度对抗、战术执着、情绪决策、信息盲点、资源误判。

**可执行流程**：情境评估 → 战略定位（该用哪一层：谋/交/兵/攻城）→ 资源与优势评估 → 方案设计 → 执行调整 → 效果评估。项目版更具体：先确保不败（风险与底线）→ 前置评估成功条件 → 集中资源攻关键节点 → 形成"决积水于千仞之溪"的势。

**对自主大脑的启示**：给"先观察后动手、小步可逆"提供了古典依据——先立于不败、算清代价、只在有明显优势处全面推进；同时给出"何时不该动手"的判断尺（攻城是最后手段）。

**来源**：`analysis/01_始计篇解读.md#五事分析法`、`analysis/01_始计篇解读.md#庙算与胜负`、`applications/03_谋攻篇应用.md#谋攻优先次序`、`applications/04_军形篇应用.md#战略评估体系`、`applications/06_虚实篇应用.md#集中优势与资源配置`。

## 4. LiaoFaJun-hub/The-Way-Seeking-Method（问道先贤·提问五门）

**定位**：把子贡、子思、墨子、商韩、阳明五家的"问"拆成五个可加载技能，并提供一个路由入口（求/照/取/拆/还）。

**核心方法论**

1. **五门定位**：求（子贡，把答案逼深一层）/ 照（子思，看"形于内"）/ 取（墨子，从"说得漂亮"拖到"不得不选"）/ 拆（商韩，拆前提、逼决断）/ 还（阳明，不答反问）。
2. **路由原则**：纯事实/技术问题**不进任何门，直接给答案**；按"关系"分流（对外求真深 / 对己看内在 / 对外逼选证 / 对局拆决断 / 对问还回去）。
3. **协同序列**：深度访谈 求→照；说服犹豫的决策者 还→取→拆；拆流行说法 拆→取；自省 照→还→求。
4. **子贡核心**：问判据不问定义；**不接受第一个答案**；在都正确的东西间问排序；问刻度不问标签；敏感问题包安全壳；提问即自画像。九钥：剥笋/设陷/设喻/迂回/求证/自陈/藏刀/压缩/掀顶。
5. **墨子核心**："非以其名也，以其取也"——**问完必落行，否则是"荡口"**（空话）；三表验问、察类明故。
6. **商韩核心**："你指的是哪个""这两个能同时成立吗"；判据只剩功用；**不做决定是最坏的决定**；带警绳——"取消辩=取消纠错"（秦以法家赢天下，十五年而亡）。
7. **子思核心**："仁形于内谓之德之行"——同样行为，内化之德与表演之别；从"不敢"到"不愿"；**审德是照见不是审判**。
8. **阳明核心**：把问题还给你；前提一错答案必错；先诊断这个人再开方；问完必须落到事上；**反假还问**（不拿反问当答不上来的挡箭牌）。

**可执行流程（子贡交互 7 步）**：识别议题与定目标 → 开放破冰 → 排序收敛 → 刻度追问 → 判据萃取 → 迂回穿透（敏感问题包壳）→ 藏刀定音（真问题最后问出）。收尾过质量自检；经验账本只追加，同一坑累计两次升格为硬规则。

**对自主大脑的启示**：这是 soul 的"问"的那一半——不接受第一层答案、不接受漂亮话、敏感事先留台阶；也是"还"的那一半——该主人自己走的决定，把问题还给他并说明为什么。

**来源**：`README.md#五门速记`、`README.md#五门协同部分`、`questioning-arts-hub/README.md#内置规则`、`zigong-questioning-art/SKILL.md#SOP总览`、`zigong-questioning-art/SKILL.md#铁律`、`mozi-questioning-art/README.md#核心内核`、`shanghan-questioning-art/README.md#边界内置警绳一票否决`、`zisi-wuxing-wisdom/README.md#核心内核`、`yangming-questioning-art/README.md#边界四条一票否决`。

## 5. nuwa-skills/hanfeizi-skill

**定位**：把《韩非子》的法治、制度设计与人性洞察蒸馏成"诊断组织问题、设计有效制度"的思维操作系统。

**核心方法论**

1. **法术势三支柱**：法（规则，无解释空间）/ 术（手段与交叉审计）/ 势（权威与顶层真心执行）。三者缺一，制度流于形式。
2. **人性趋利**：行为由利益驱动，不试图改变人性，而是设计让人性为组织工作的制度。
3. **制度优先**：人出问题先看制度有没有问题——**改制度，不改人**。"销售互抢客户"是激励结构扭曲，不是人品问题。
4. **赏罚必须可信**："赏莫如厚而信，罚莫如重而必"；**批评不是罚**（工资没少、职位没降，理性人的计算没变）。
5. **参验**：信息交叉验证，不依赖单一来源；用"寓言校验"检查结论是因果还是巧合。
6. **不期修古**：制度是工具，工具要适配问题；反对把传统当不可变更的真理（守株待兔）。
7. **七条实用法则**：利益动机 / 制度优先 / 寓言校验 / 矛盾暴露 / **成本可信**（宁可少承诺也不空头支票）/ 信息独立 / **最小特权**（不给超出职责需要的权力）。
8. **说难**：说服的关键是理解对方利益，而不是把道理讲得更对。

**可执行流程**：先问"利益在哪里" → 再看制度与激励结构是否扭曲行为 → 拆方案内在矛盾 → 交叉验证信息 → 设计"规则明确 + 可审计 + 惩罚可信"的最小改动 → 落到可执行的赏罚。

**对自主大脑的启示**：给 soul 提供"法度"与"参验"两条硬约束——自己也要受规则约束（留痕、可审计、可回滚），以及不轻诺、不空头支票的自我要求。

**来源**：`README.md#蒸馏了什么`、`README.md#效果示例`、`README.md#调研来源`。

## 融合结论

五套东西不是并列的五个口味，而是**一条流水线上的五道工序**，可以按顺序咬合：

1. **丁元英定基调（为什么）**：先分清这是规律问题还是愿望问题，承认边界、准备退出。这一步决定"要不要做"，防止自主大脑被主人的期待拖着走。
2. **毛泽东定靶心（做什么）**：列矛盾、抓主要矛盾、看力量对比、判断阶段。把"千头万绪"压缩成"这一阶段只解决这一件事"，并强制收口到"怎么办"。
3. **孙子定算法（做多大、什么时候做）**：五事七计做庙算，先立于不败，算代价与优势倍数，能伐谋就不攻城。把靶心翻译成"代价可承受、胜率足够"的具体动作。
4. **韩非定制度（凭什么可以做、做完怎么算数）**：法（规则允许吗）、术（信息交叉验证了吗）、势（谁拍板）；赏罚可信、最小特权、不空头支票。这一步是授权的闸门，也是复盘的标尺。
5. **问道五门定沟通（怎么问、问到什么程度、什么时候还回去）**：求——不接受第一层答案；取——只认能兑现的；拆——拆前提与伪二选；照——看是内化还是表演；还——该主人自己走的决定，把问题还给他。

串起来就是自主大脑的一轮完整思考：**辨规律 → 抓主要矛盾 → 算代价与胜率 → 过制度与授权闸门 → 取最小可逆动作 → 执行留痕 → 参验复盘 → 判断该不该请示**。价值观层面则收敛成四句话：按规律办事不按愿望办事；先看事实再谈道理；先胜后战，小步可逆；该问的问到底，该还的还回去。
